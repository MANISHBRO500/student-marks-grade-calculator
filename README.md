# Student Marks and Grade Calculator

This project contains a Python script and an HTML mockup for a student marks and grade calculator.

## Files

- `student_marks_calculator.py` - Python command-line version
- `student_marks.html` - browser-based IDLE-style version

## Run the Python script

```bash
python student_marks_calculator.py
```

## Open the HTML version

Open `student_marks.html` in a browser to see the calculator UI.

## Features

- Input marks for multiple subjects
- Calculate total marks
- Calculate average percentage
- Determine grade (A+, A, B, C, D, E, F)
- Show pass/fail status
- User-friendly console-style output
